# Originalidade

Esta aplicacao foi escrita do zero.

O material analisado anteriormente foi usado somente para levantar requisitos
tecnicos de interoperabilidade:

- existe uma ponte local para AEDT/HFSS;
- o modulo AEDT abre projeto, seleciona design, altera variaveis e roda analise;
- o modulo VNA opera por comandos locais com conceitos de frequencia, IFBW,
  potencia, sweep unico e exportacao de dados;
- arquivos Touchstone sao uma saida natural para comparar simulacao e medicao.

Nao ha copia de codigo fonte, nomes internos proprietarios, patches binarios,
assets, chaves, licencas ou engenharia de codigo recuperado dentro deste projeto.
